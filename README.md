# REACH_SeniorDesign
This the GitHub for code used in our senior design project. The Boron404x folder contains the code used to communicate between the nodes (dashboard/database and the ESP8266). The ESP8266 folder contains code used to control and get readings from the modular components on the PCB. There are also algorithms used for scheduling and calculations. The Grafana Dashboard folder contains code used to get information from the dashboard and update the database, and vice versa. The INA219 folder contained code used for testing and getting current sensor readings. Overall, this code should be helpful in getting a better understanding of what was going on behind the scenes of our project and is a key part of making sure REACH functioned properly.
